# v2.0.0 / Formation & Facing

- Seven rear-view variants: blade, knight, archer, mage, spear, bat, bomber.
- Cannon barrel and tower turret aim; viewer-relative headings on both seats.
- Same-ground and same-air collision layers, opponent hard core, allied soft yielding.
- Original radii retained; relative mass added for formation contact.
- Full-body river constraints, A* routing, cached clearance grids, no live-building traversal.
- Destroyed buildings cease to block; fixed cannon deployment validates occupied space.
- Tower/ground depth sorting, occluded-friendly position hints.
- Front/rear roster toggle, optional hitbox overlay, accurate placement previews.
- Version-identifying API and old-match safety; same Worker/DO migration.

Unchanged: 8 roles and costs, attack damage and range, original victory/timer rules, private 1v1, CPU difficulty, reconnect, surrender and rematch. No global taunt, projectile interception, new spells, new ranks or server deployment was added.
