TINY SIEGE v5 Cloudflare公開

既に tiny-siege Workerを公開している場合は UPDATE-TO-V5.html の方が短い手順です。

  1. GitHubリポジトリ tiny-siege のルートにこのプロジェクトの中身を置く。
  2. Cloudflare Workers & PagesでGitHubリポジトリを接続。
  3. Project name: tiny-siege
  4. Build command: 空欄
  5. Deploy command: npx wrangler deploy
  6. Root directory: /
  7. Deploy成功後、/api/configでv5.0.0を確認。
https://tiny-siege.miru0104.workers.dev/api/config

Worker名やDurable Object bindingは同梱の wrangler.jsonc に定義されています。
