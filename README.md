# TINY SIEGE v3.0.0

2Dリアルタイム1対1攻城ゲームの試作版です。Cloudflare Workers + Durable Objects でプライベート対戦、ブラウザだけでCPU練習ができます。

## v3の主な変更

- ユニット総数を **8体 -> 9体** に拡張。
- 新ユニット **ストーンゴーレム** を追加。
  - 敵兵を攻撃せず、敵のタワー・本拠地・砲台など **建物だけを狙う**。
  - HP 3350 / 建物攻撃 295 / コスト 6 / 移動速度 21。
  - 大型の地上ユニットとして半径30・高massを持ち、編成の壁になりやすい。
- 対戦デッキを **9体の中から6体選択**する方式に変更。
- ホーム・待機室から開ける **デッキ編集画面**を追加。
- 6体未満ではCPU戦開始・オンライン準備OKができない。
- デッキはブラウザのlocalStorageに保存。
- オンラインでは各プレイヤーが自分の6体デッキをサーバーへ準備時に送信し、対戦開始時にそれぞれのデッキを使用。
- 相手のデッキ内容は通常の状態スナップショットには含めず、待機室では選択数だけを表示。

## 現在の9ユニット

1. アッシュ剣士 - 近接アタッカー
2. アイアン衛士 - 近接タンク
3. リーフ弓兵 - 遠距離・対空
4. ルーン術師 - 範囲攻撃・対空
5. スパーク槍兵 - 中距離・低コスト
6. ムーンバット - 飛行・3体編成
7. ポット爆弾兵 - 地上範囲攻撃
8. ボルト砲台 - 防衛建物
9. ストーンゴーレム - 建物特攻・超重量

おすすめ初期デッキは **剣士 / 衛士 / 弓兵 / 術師 / 爆弾兵 / ゴーレム** です。

## すぐ遊ぶ

`PLAY-OFFLINE.html` をEdge / Chromeで開けばCPU練習できます。インストールやサーバー起動は不要です。

## 既存のCloudflare版をv3へ更新

すでに `tiny-siege` をGitHubとCloudflareに接続済みなら、Workerを作り直す必要はありません。

1. このフォルダの **中身** をGitHubの `tiny-siege` リポジトリ直下へアップロードします。
2. `package.json` と `wrangler.jsonc` がリポジトリ最上位に見える状態にします。
3. `main` へCommitします。例: `Upgrade Tiny Siege to v3.0.0`
4. Cloudflare Buildsが `npx wrangler deploy` を実行し、成功するまで待ちます。
5. 公開URLの `/api/config` を開き、次を確認します。

```json
{
  "game": "tiny-siege",
  "version": "3.0.0",
  "units": 9,
  "physicsVersion": 2,
  "maxDeck": 6
}
```

6. 対戦する全端末で `Ctrl + F5` などの強制再読み込みをします。
7. v2以前の進行中ルームではなく、新しくルームを作って確認してください。

より詳しい手順は `UPDATE-TO-V3.html` と `docs/DEPLOY_CLOUDFLARE.md` を参照してください。

## デッキ編集の仕様

- ライブラリ: 9体
- 対戦デッキ: **ちょうど6体**
- 同じユニットを2枚入れることはできません。
- 手札はデッキ6体のうち4体。使用後は残り2体を含む循環キューへ戻ります。
- CPUはおすすめ初期デッキを使用します。
- オンラインでは双方が準備OKを押した時点のデッキを使用します。
- 準備OK後は一度準備を取り消さないと編集できません。
- 対戦中は編集できません。

## ストーンゴーレムの実装方針

`docs/concepts/stone-golem-concept.png` のコンセプトを、既存キャラと同じCanvasベクター描画へ簡略化しています。外部画像をゲーム中に読み込まず、苔・石体・青いルーン・巨大な拳・背面意匠をコードで描画します。

ゲームロジックでは `buildingOnly: true` を持ち、敵ユニットをターゲット候補から除外します。敵のタワー、本拠地、配置された敵砲台など建物を優先して進みます。敵兵からの攻撃や地上衝突は通常どおり受けます。

## 開発コマンド

Node.js 22+ を想定しています。

```sh
npm install
npm run check
npm test
npm start
```

別ターミナルから:

```sh
npm run test:network
```

Cloudflareへの手動公開:

```sh
npm run login
npm run whoami
npm run deploy
```

GitHub連携を使っている場合は通常、mainへのCommitだけで自動公開されます。
