# TINY SIEGE v15.0.0

Cloudflare Workers + Durable Objects で動く、オリジナル2Dリアルタイム攻城ゲームです。

## v15 の変更

- **マッドドラゴン調整**：攻撃射程を155から78へ短縮。HP2000・攻撃200・半径45の範囲攻撃・2秒泥沼は維持。
- **穴掘りティガー調整**：攻撃30→15。地下移動を約0.9〜2.8秒へ遅延し、遠距離奇襲の予告時間を増やしました。
- 新ユニット **吹き矢ゴブリン**：3コスト / HP240 / 攻撃110 / 0.5秒間隔 / 射程220。地上・空中へ対応する超長射程の低耐久射手です。
- 新設置物 **レーザー塔**：5コスト / HP2000 / 射程220。単体へ継続レーザーを照射し、同じ対象を1.5秒狙い続けるごとにDPSが20→40→80→160…と倍化。上限なし。対象変更時は20DPSへリセット。
- v14の地下奇襲・泥沼、v13のターゲットロック、v12の8枚デッキと設置物射程プレビューを維持。
- カードプールは **24枚（21ユニット＋3呪文）**、デッキは8枚、手札は4枚。
- `physicsVersion=13`。旧進行中ルームとは混在させません。

## Cloudflare更新

1. このフォルダの中身を `Rin447/tiny-siege` のルートへ上書きアップロード。
2. `main` に Commit（例：`Upgrade Tiny Siege to v15.0.0`）。
3. Cloudflare Workers のBuild/Deploy成功を確認。
4. `/api/config` で次を確認します。

```json
{
  "version": "15.0.0",
  "cards": 24,
  "units": 21,
  "spells": 3,
  "physicsVersion": 13,
  "maxDeck": 8
}
```

公開後は両端末を強制再読み込みし、新しいPASSのルームで確認してください。
