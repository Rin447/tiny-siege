# TINY SIEGE v18.1.0

Cloudflare Workers + Durable Objects で動く、オリジナルの2Dレーンバトラーです。**30枚（26ユニットカード＋4呪文）から8枚**を選び、CPU練習またはプライベート1v1を遊べます。

## v18.1.0 - DETAIL DEMO RENDER FIX

- スパーキーのカード詳細LIVE BATTLE DEMOで、初回砲撃後に戦場が斜めに重なり続ける不具合を修正。
- sparkblastの描画時間参照を修正し、Canvas変形を各フレームで初期化。
- 投射物描画のsave/restoreを保護し、別キャラへ移動した場合も正常な描画を維持。
- カード性能・対戦ロジックは変更なし。`physicsVersion=17`を維持。

## v18.0.0 - LONGSHOT & VOLTAGE

- **プリンセスアーチャー**：3コスト / HP300 / 攻撃275 / 3秒間隔 / 射程350 / 半径70範囲 / 地上＋空中。橋を渡らず敵サイドタワーへ届く超長射程。矢の雨（330）で一撃処理可能。
- **ザップ**：2コスト / 半径78 / 225ダメージ / 1.5秒スタン。敵ユニット・建物の攻撃対象を解除し、レーザー塔の増幅とスパーキーの充電もリセット。
- **スパーキー**：6コスト / HP1500 / 攻撃1200 / 射程145 / 半径90範囲 / 地上のみ。敵を見つけていなくても配置直後から常時3.5秒充電し、満充電で待機。発射後は再充電。ザップで0に戻る。
- **ルーン術師**：4 → 3コスト。
- **リーフ弓兵**：3 → 2コスト。
- **クラッグバーサーカー**：攻撃間隔 1.6 → 1.8秒。
- v17.1のネクロマンサー7.5秒召喚、ダークネクロマンサー6.5秒召喚・地上近接は維持。

## バージョン運用

細かな調整・UI改善・不具合修正は `18.1.0`, `18.2.0` のように更新し、新キャラ・設置物など大きな追加時は `19.0.0` のようにメジャー番号を上げます。

## GitHub / Cloudflare 更新

1. ZIPを展開してリポジトリへ上書きアップロード。
2. `main` に Commit（例：`Fix Tiny Siege detail demo rendering in v18.1.0`）。
3. Cloudflareの自動デプロイを待つ。
4. `/api/config` が次の値なら更新成功です。

```json
{
  "version": "18.1.0",
  "cards": 30,
  "units": 26,
  "spells": 4,
  "physicsVersion": 17,
  "maxDeck": 8
}
```

オフライン確認は `PLAY-OFFLINE.html` をブラウザで開いてください。オンライン1v1はCloudflareへのデプロイが必要です。
