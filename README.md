## v19.3.0 - SUMMON DELAY SYSTEM
- ユニットカードに召喚準備時間を追加。基準は 1コスト0.4秒 / 2コスト0.5秒 / 3コスト0.7秒 / 4コスト0.9秒 / 5コスト1.2秒 / 6コスト1.5秒 / 7コスト1.8秒。
- ストーンゴーレムは特別に2.5秒、スパーキーは1.8秒。
- 穴掘りティガーは地下移動を召喚時間として扱い、追加の待機時間はなし。
- 召喚中は移動・攻撃・索敵をせず、ターゲット不可・完全無敵・当たり判定なし。
- 召喚地点に陣営色のサークル、半透明シルエット、残り時間ゲージを表示。
- ネクロマンサー / ダークネクロマンサー / ドスランボスの配置時召喚は、本体の召喚完了と同時に発動。
- 能力で呼ばれたボーン / バット / ランボス、ゴーレム死亡後のちびゴーレムには追加の召喚待ち時間を付けない。
- ボルト砲台・レーザー塔はv19.2の1タップ配置を維持し、タップ直後から建設ゲージを開始。
- physicsVersion: 23。
