# TINY SIEGE v17.0.0

Cloudflare Workers + Durable Objects で動く、オリジナルの2Dレーンバトラーです。**27枚（24ユニットカード＋3呪文）から8枚**を選び、CPU練習またはプライベート1v1を遊べます。

## v17.0.0 - SUMMONERS UPDATE

- **ネクロマンサー**：6コスト / HP1350 / 攻撃125 / 地上＋空中 / 遠距離範囲攻撃。配置した瞬間にボーン3体を召喚し、その後も生存中は**6秒ごとに3体**を追加召喚します。
- **ダークネクロマンサー**：5コスト / HP1150 / 攻撃165 / 地上のみ / 遠距離単体攻撃。配置した瞬間にムーンバット2体を召喚し、その後も生存中は**5秒ごとに2体**を追加召喚します。
- **アッシュ部隊**：5コスト。既存のアッシュ剣士3体を、敵方向へ**前1体・後ろ2体**の三角陣形で同時展開します。
- 3枚ともカード詳細に本番の戦闘エンジンを使った専用 **LIVE BATTLE DEMO** を追加。ネクロ系は初回召喚と定期召喚、アッシュ部隊は三角陣形から後衛へ突入する様子を確認できます。
- 配置時召喚はカード効果の一部として扱うため、ユニット上限に空きがない場合は「本体だけ出て召喚できない」状態にならないよう、初回召喚分まで配置前に確保します。

## v16シリーズも継続

v16.4.0までの、能力専用LIVE DEMO、マイリスト、3列デッキ編集、スペル陣営カラー、スマホ設置物修正、ティガー攻撃20、ムーンバット4体などはすべて維持しています。

バージョン運用は、細かな調整・UI改善・不具合修正は `17.1.0`, `17.2.0` のように更新し、新キャラや大きな追加時は `18.0.0` のようにメジャー番号を上げます。

## Deploy

1. ZIPを展開し、中身全部を `Rin447/tiny-siege` のルートへ上書き。
2. `main` に Commit（例：`Upgrade Tiny Siege to v17.0.0`）。
3. Cloudflare の自動 Build/Deploy を待つ。
4. `/api/config` を確認。

```json
{
  "version": "17.0.0",
  "cards": 27,
  "units": 24,
  "spells": 3,
  "physicsVersion": 16,
  "maxDeck": 8
}
```

`physicsVersion=16` です。新しい召喚処理と新カード3枚が実戦状態に影響するため、公開後はPC・スマホとも強制再読み込みし、**新しいルーム/PASS**で対戦してください。
