# TINY SIEGE v5.0.0

2Dリアルタイム1対1攻城ゲームの試作版です。全15体から6体を選んでデッキを組み、CPU戦または6桁PASSのプライベートオンライン対戦を遊べます。

## v5の主な変更

- ユニット総数を **12体 -> 15体** に拡張。
- **ルミナ司祭**: 周囲の傷ついた味方ユニットを115回復。建物は回復しません。
- **フロストシャーマン**: 氷弾で地上ユニットの移動速度を38%、攻撃速度を28%低下させ、3秒間妨害。アイアンボアのチャージ距離も削ります。
- **ストームハーピー**: 飛行・遠距離。雷が最大3体まで近くの敵兵へ連鎖します。
- **アイアンボア強化**: 軽量地上ユニットを押しのけて進みやすくしました。橋の小型兵渋滞を突破しやすくなっています。
- デッキは引き続き **15体から6体**。手札4＋控え2で循環します。
- 物理挙動更新のため `PHYSICS_VERSION = 3`。更新前の進行中ルームは安全に終了します。

ブラウザにv4以前のデッキが残っている場合は引き継ぎます。新キャラをすぐ試すなら「デッキ」→「おすすめに戻す」を押してください。

## すぐ試す

`PLAY-OFFLINE.html` をEdge/Chromeで開くとCPU戦を試せます。オンライン公開にはCloudflare Workersへのデプロイが必要です。

## 公開済み tiny-siege をv5へ更新

1. このフォルダの中身をGitHub `Rin447/tiny-siege` のルートへ上書きアップロード。
2. `main` へCommit。例: `Upgrade Tiny Siege to v5.0.0`
3. Cloudflare Buildsが `npx wrangler deploy` を実行して成功するまで待つ。
4. `https://tiny-siege.miru0104.workers.dev/api/config` で `version=5.0.0`, `units=15`, `physicsVersion=3`, `maxDeck=6` を確認。
5. 両PCで `Ctrl + F5` し、新しいルームを作成。

詳しくは `UPDATE-TO-V5.html` と `docs/DEPLOY_CLOUDFLARE.md` を参照してください。
