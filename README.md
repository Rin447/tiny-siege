# TINY SIEGE v25.1.0


## v25.1.0 - DRAG DECK UPDATE

- デッキ編集でカード一覧から8枠へ直接ドラッグして追加・入れ替えできるようになりました。
- デッキ枠同士のドラッグで8枚の順番も入れ替えできます。
- タップ/クリックは従来どおりカード操作を開き、PCは約10px移動、スマホは約0.18秒長押し後の移動でドラッグへ切り替えます。
- ドラッグ中は追従カード、置ける枠、現在のドロップ先を視覚表示します。戦闘ロジックは変更せず `physicsVersion: 31` を維持します。

## v24.1.0 - MEGA FLIGHT UPDATE

- **メガナイトのジャンプ移動を固定1.5秒化**。ジャンプ距離に関係なく、飛び始めてから着地まで必ず1.5秒かかります。
- **空中表現を強化**。ジャンプ中は大きく浮き上がり、地面の影、風線、弧状の軌道、着地点リングで「飛んでいる」ことが分かる表示へ変更。
- **着地点を離陸時に固定**。飛び始めた後は対象が移動しても着地点は変わりません。
- `physicsVersion: 30`。オンライン対戦ではV24.1.0同士で揃えてください。

## 既存の重要仕様

- **スタン**: 通常攻撃クールタイムをリセットせず、スタン中だけ進行停止。解除後に残り時間から再開。タワー・設置物も同じ。
- **レーザードラゴン / レーザー塔**: 同じ対象へ1.5秒照射するごとに 20 → 40 → 80 → 160... DPS と倍化。対象変更・射程外・スタンで初期化。
- **V22位置操作系**: ウィンドメイジ、グラビティオーブ、サイクロンの押し引きと重量差を維持。
- **召喚ディレイ**: コスト別の召喚準備時間。召喚中はターゲット不可・無敵・衝突なし。
- **更新履歴HTML**: バージョン別ファイルは増やさず、`UPDATE-HISTORY.html` 1枚へ追記します。
