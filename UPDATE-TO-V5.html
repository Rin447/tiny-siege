TINY SIEGE v5.0.0

ルミナ司祭・フロストシャーマン・ストームハーピーを追加し、アイアンボアの押しのけ能力を強化した15体版への更新手順です。

v5: 全15体 / デッキ6体 / 回復 / 減速 / 連鎖雷 / ボアの軽量兵押しのけ / Physics v3。

1ZIPを展開

tiny-siege-cloudflare-v5.zipを展開し、外側フォルダではなく中身を使います。

tiny-siege-cloudflare-v5/
  package.json
  wrangler.jsonc
  public/
  src/
  tests/
  docs/
  ...

2GitHubへ上書き

GitHubの Rin447/tiny-siege を開き、Add file → Upload files。展開した中身全部をルートへ上書きしてください。

3mainへCommit

例: Upgrade Tiny Siege to v5.0.0

4Cloudflareの成功を待つ

Workers & Pages → tiny-siege → Deploymentsで最新Buildが緑のチェックになるまで待ちます。既存のDeploy command npx wrangler deploy は変更不要です。

5API確認

次を開きます。

https://tiny-siege.miru0104.workers.dev/api/config

version: 5.0.0、units: 15、physicsVersion: 3、maxDeck: 6なら成功です。

6ゲーム確認

  1. 両PCで Ctrl + F5。
  2. 新しいルームを作る。
  3. 「デッキ → おすすめに戻す」で司祭・シャーマン・ハーピー・ボアを確認。
  4. 司祭が傷ついた味方兵を回復し、建物は回復しない。
  5. シャーマンの氷弾で地上兵が青い減速表示になる。
  6. ハーピーの雷が密集した敵兵へ連鎖する。
  7. ボアがモスリングなど軽量地上兵を押しながら前進できることを確認。
物理ルールがv3へ変わったため、更新前から進行中だった試合は継続せず、新しいPASSのルームで確認してください。
