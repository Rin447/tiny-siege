TINY SIEGE v3.0.0

ストーンゴーレム＋6体デッキ編集版への更新手順です。

今回の追加: 全9体 / デッキ6体 / ストーンゴーレム / CPU・オンライン両対応。既存の tiny-siege Workerをそのまま更新できます。

1ZIPを展開

tiny-siege-cloudflare-v3.zip を「すべて展開」します。外側フォルダではなく、中にあるファイルとフォルダをアップロードします。

tiny-siege-cloudflare-v3/
├ package.json
├ wrangler.jsonc
├ public/
├ src/
├ server/
├ tests/
├ docs/
└ ...

2GitHubへ上書き

GitHubの tiny-siege リポジトリで Add file → Upload files を選び、展開した中身をまとめてアップロードします。

注意: ウェーブレングス用の janken-game には入れません。tiny-siege を更新します。

リポジトリを開いたとき、最上位に package.json と wrangler.jsonc が見えれば配置は正解です。

3mainへCommit

「Commit directly to the main branch」を選び、例として Upgrade Tiny Siege to v3.0.0 でCommitします。

4Cloudflareで成功を確認

Workers & Pages → tiny-siege → Deployments を開き、最新Buildが緑のチェック、新しいVersionがActive deploymentになればOKです。

設定値
Build command空欄
Deploy commandnpx wrangler deploy
Root directory/
Production branchmain

5API確認

公開URLの末尾に /api/config を付けます。

{
  "game": "tiny-siege",
  "version": "3.0.0",
  "units": 9,
  "physicsVersion": 2,
  "maxDeck": 6
}

6ゲーム確認

  1. 全端末でCtrl+F5。
  2. 「デッキ」を開き、9体から6体選べることを確認。
  3. ストーンゴーレムを入れて保存。
  4. CPU戦または新規オンラインルームを開始。
  5. ゴーレムが敵兵を攻撃せず、建物へ向かうことを確認。
  6. オンラインでは双方がそれぞれ選んだ6体だけで手札が循環することを確認。
ゴーレム暫定性能: コスト6 / HP3350 / 建物攻撃295 / 速度21。プレイテストで調整する前提です。
