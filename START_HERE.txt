TINY SIEGE v46.0.0 - HUNTER & ROCKET UPDATE (FULL PACKAGE)

QUICK START
1) CPU practice: double-click START-PRACTICE-WINDOWS.bat
   - Or open PLAY-OFFLINE.html directly.
2) Local server / online-room test on your PC: double-click START-LOCAL-WINDOWS.bat
   - Browser: http://localhost:3000
3) Cloudflare deploy:
   01-SETUP-CLOUDFLARE.bat
   02-LOGIN-CLOUDFLARE.bat
   03-DEPLOY-CLOUDFLARE.bat

DEVELOPER COMMANDS
- npm run check
- npm test
- npm run build:offline
- npm start

SOURCE LAYOUT
- public/index.html : current v46 browser game (canonical client source)
- src/game-core.js : deterministic server-side core generated from public/index.html
- src/room-model.js : authoritative 1v1 room logic
- src/worker.js : Cloudflare Worker / Durable Object entry
- server/dev.mjs : zero-dependency local Node server
- scripts/sync-game-core.mjs : regenerates current server core
- scripts/build-offline.mjs : regenerates PLAY-OFFLINE.html
- tests/ : package/current-core smoke tests

IMPORTANT
When public/index.html is edited, run `npm run sync:core` before testing/deploying.
`npm run check` automatically runs this synchronization first.
