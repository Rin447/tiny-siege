TINY SIEGE v3.0.0

今回の更新:
- 全9ユニット
- 新キャラ「ストーンゴーレム」追加（敵兵を無視し建物だけを攻撃）
- 9体から6体を選ぶデッキ編集画面
- CPU戦 / オンライン戦の両方で選んだデッキを使用

まずCPUで試す:
  PLAY-OFFLINE.html をダブルクリック
  -> 「デッキ」を開く
  -> 6体を選ぶ
  -> CPU練習を開始

既存のCloudflare版を更新:
1. ZIPを展開
2. 展開したフォルダの中身を GitHub の tiny-siege リポジトリ直下へアップロード
3. main に Commit（例: Upgrade Tiny Siege to v3.0.0）
4. CloudflareのDeploymentsで成功を確認
5. https://あなたのURL/api/config で version 3.0.0 / units 9 / maxDeck 6 を確認
6. 全端末で Ctrl + F5
7. 新しいルームで対戦

重要:
- wavelength側の janken-game / dark-mode-0e8f には上書きしない
- tiny-siege 用のリポジトリとWorkerを更新する
- package.json と wrangler.jsonc はGitHubの一番上の階層に置く
